## The course at a glance
| | |
|---|---|
| Duration | 5 years, single cycle, 300 ECTS credits (CFU) |
| Degree class | LM-4 c.u., Architecture and Building Engineering-Architecture |
| Admission | Limited places, with a national admission test. [Places and deadlines 2026/27](/iscriversi/primo-anno/#anno-accademico-202627) |
| Qualification | After the State Examination, it qualifies you to practise both as an engineer and as an architect. Recognised in the European Union |
| Running since | 2003 |
